# 8BIT POS — браузерная демонстрационная версия

Совместимо с Java 21, Maven, SQLite. Для веб-сервера используется встроенный в Java
`com.sun.net.httpserver.HttpServer` (новых библиотек не требуется).

## Запуск в GitHub Codespaces

Из корня **Java-проекта**, в котором находится `pom.xml`:

```bash
mvn clean test
mvn compile exec:java
```

Запустится сервер на порту 8080. В Codespaces открой вкладку **Ports**, найди 8080
и нажми **Open in Browser**. Порт рекомендуется оставить **Private**.
Остановить сервер: `Ctrl+C` в терминале.

### Где находится Java-проект в репозитории

В репозитории `Zahrain132132/8bit-pos-kpo` путь:
`/workspaces/8bit-pos-kpo/8bit-pos/8bit-pos`.

### API

- `GET /api/products` — каталог из SQLite
- `GET /api/cart` — текущее содержимое чека
- `POST /api/cart/add` — `barcode=...&quantity=...`
- `POST /api/cart/set` — `barcode=...&quantity=...` (0 удаляет товар)
- `POST /api/cart/remove` — `barcode=...`
- `POST /api/cart/clear` — очистка чека
- `POST /api/checkout` — продажа и **транзакционное** списание остатков SQLite

Данные `data/pos.db` хранятся локально внутри Codespace. Если база новая и пустая,
создаются 8 демонстрационных товаров. Если база уже содержит товары, данные
не заменяются.

### Важные ограничения учебной версии

- Одна общая корзина на весь запущенный сервер; нет авторизации и разных кассиров.
- Финансовый платёж не выполняется; «оформить покупку» означает списать остатки.
- История чеков и цены в копейках/центах будут улучшены позже.
- Порт Codespaces оставь **Private**: сервер рассчитан на локальную учебную демонстрацию.

### Дизайн

Чёрная палитра, зелёные пиксельные акценты, лёгкий CRT-эффект, едва заметный
глитч. Анимации отключаются системной настройкой «уменьшить движение».
Шрифты `Press Start 2P` / `IBM Plex Mono` загружаются из Google Fonts, при
недоступности сети используются системные моноширинные шрифты.
